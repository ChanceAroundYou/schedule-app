## 快速添加：窄屏一个圆钮 `+` / `×`，日期 / 时间分两层（2026-10-07）

**窄屏（≤900px）默认收起成右下角一个圆钮，点开才展开横条、再点原地收起**；宽屏常驻展开 ——
桌面有地方，多一次点击只是碍事。状态是 `QuickAdd` 里的 `expanded = useState(!narrow)`，
**不落盘**（这是「这一次怎么用」，不是用户偏好）。`narrow` 用 `useIsNarrow()` 同步初始化，
所以首帧就是对的、不会闪一下。

**那个圆钮是一直在的**（收起 `+` / 展开 `×`），**不是「展开就消失、收起键搬进横条」** ——
横条就是从它这儿弹出去的，它不能跟着横条一起 `display:none`，那样就没有「弹出来」可言。
三个几何量互相咬合，改一个要一起看：

| 量 | 值 | 为什么 |
|---|---|---|
| 横条 `left` / `right` | `13px` / `74px` | 前者和宽屏那条基线左右对齐；后者 = `16 + 48 + 10`（圆钮右偏移 + 直径 + 缝） |
| 横条 `bottom` | `calc(64px + env(safe-area-inset-bottom, 0px))` | 64 = 标签栏 56 + 8px 缝 |
| 圆钮 `bottom` | `calc(fabBottom px + env(…))` | `fabBottom = max(58, 64 - 24 + barH/2)` |

- **圆钮和横条竖直居中**：按横条的**实测高度**反推，不是写死 —— 横条被输入框撑成两行时
  圆心跟着往下走。58 是下限（再低就压到标签栏上）。
- **这些几何量写在 `Shell.tsx` 的内联 `style` 里，不只是 CSS 媒体块里。** 媒体查询按
  **真实**视口宽度走，而探针是「JS 判窄、CSS 判宽」的环境（见踩坑 24），只写媒体块的话
  那边量不到。`margin: 0` 也必须写在内联里 —— `position: fixed` + `left/right` 的定位里
  `margin` 会**再加一层**偏移（`right: 74px` 实际让出 96px，见踩坑 38）。
- 弹出动画 `@keyframes fastPop` 挂在 `.fast-add:not([hidden])` 上，配内联的
  `transform-origin: 100% 50%`（= 圆钮的左边缘）。挂 `:not([hidden])` 是因为 `display:none`
  会把动画移除、再显示时重新开始。`.fast-fab` 的 `z-index` 是 **39**：要压住正文，但
  **必须低于抽屉遮罩的 40**，抽屉打开时它该被罩住。
- **输入框是 `<textarea rows={1}>`，默认一行、内容多了自己撑开。** 撑开靠 `useLayoutEffect`
  里「先把 `height` 归零、再读 `scrollHeight`」—— **不归零的话它只会越长越高**，删掉一行
  也缩不回去（`scrollHeight` 里含当前 height）。回车仍然是保存，换行让给 `Shift + Enter`。
- **「保存」是个 ✓ 图标，摆在日期按钮前面**，两者都是 `30px` 高。日期按钮里要摆**两行
  10px 的小字**（两行加行距约 22px）—— **高度不能跟着内容变**，否则「只有日期」和
  「日期 + 时间」两种状态横条会跳一下。
- 「N」快捷键在窄屏下**先展开再聚焦**（收起的横条是 `display:none`，聚焦不上去），展开后
  等一次 effect（`focusOnExpand` ref）再 `focus()`。
- 收起的横条靠 `hidden` 属性藏（Tailwind 4 preflight 的
  `[hidden] { display: none !important }` 压得住语义样式模块里没分层的
  `.fast-add { display: flex }`）。**别改成自己加一个 `display:none` 的类** —— 那就得跟
  层叠顺序再斗一次（见踩坑 17）。

**点空白收起是「两级」，而且两级在同一个 handler 里**（`Shell.tsx` 的 `QuickAdd`）：面板
开着 → 先收面板、横条留着；面板没开 → 才收横条。宽屏没有「收横条」这一级（`if (narrow)`）。

> **不能两处各挂一个 `document` 上的 capture 监听。** 面板（`.when-pop`）是横条的 **DOM
> 子节点**，而它的定位是 `position: fixed` —— 几何上离得很远，DOM 上却是一家人。「点在
> 面板里」在两边的 `contains()` 判断里都成立，谁先跑只看注册顺序，必然有一边误判（先收
> 横条的话，用户点空白想收面板，整个输入框也没了）。所以 `WhenPop` 里**只剩 Escape**，
> 外面的点击整件事收在 `QuickAdd`：`barRef` / `fabRef` 的 `contains()` 放行。

### 日期 / 时间那块是一个两层折叠面板（`ui/WhenPop.tsx`），不是两个浮层

上面一层日期、下面一层时间，各点各的标题行开合，**同时只开一层**。

- **每行是三个平级的 `<button>`**：`.wp-head`（开合）+ `.wp-act`（清空 / 跳过）+
  `.wp-cv`（箭头，也是开合）。**不能嵌套** —— 嵌套 button 是非法 HTML，浏览器会把里层
  那个甩到外面去；换成 button 里塞 `role="button"` 的 span 也一样是嵌套交互元素，读屏会
  当成两个控件来回问。
- **「清空 / 跳过」在箭头左边**，`.wp-head` 仍然是 `flex: 1` 吃掉剩下的宽度。
  **面板底部没有出口按钮** —— 那个「收起」删掉了，点面板外面就收（见上）。
- **打开时先开哪层看「有没有日期」**：没有（待办箱）先开日期层；已经有 —— **包括跟着 tab
  来的默认值**（今天页 = 今天、日程页 = 光标那天）—— 先开时间层。判据是 `effDate`，不是
  `pendingDate`。**点中某天 → 自动收起日期层、切到时间层**（挑完日期下一步几乎总是挑时间）。
- **「不设置」拆成两个，贴在各自那行上**，文案跟着状态走：有值写「清空」、没值写「跳过」
  （`actOf`）。不是「取消」：取消是「我刚才白点了」，不设置是「这一条就是没有日期也没有
  时间」。在待办箱里后者是常态，在「今天」页上它更是唯一能把默认的今天摘掉的路。
- **`pendingDate` / `pendingTime` 是三态**：`undefined`（没表过态 → 用默认）、`null`
  （明确说不要）、`'…'`（选了这个）。**混成两态的话「清空」会被 tab 默认值顶回来**，
  点了跟没点一样 —— 和 `navBottom` 是同一类坑（见踩坑 16）。
- **按钮上那两行写的是生效值**（`10/7` + `08:00`，`D.fmtSlashMD`），跟面板里写的是同一个
  `effDate` / `effTime`。**别一个写 `pending*`、一个写 `eff*`** —— 那会出现「按钮写
  10/7、面板高亮别的日子」。
- 生效值优先级：**面板选的 > 文本解析 > tab 默认**，日期与时间都是。（时间这一项曾经是
  `parsed.time ?? pendingTime`，漏了「面板优先」。）
- **不做「最近用过的日期」快捷推荐**：面板里再塞一行 chips 就放不下了，而且这是个日程管理
  软件 —— 日期是**选出来**的，不是**猜出来**的。

### 转盘拆成了两半（`ui/Clock.tsx`）：`ClockBody` 是本体，`ClockPop` 是抽屉里那个浮层

- 表盘本体**只有一份**，两处共用。`ClockPop` 只是给它套上定位 + 「确定 / 取消」。
- **两条路的出口语义相反**：快速添加是实时的（拨一下立刻回传，没有「确定」），抽屉是
  「取消 = 反悔」（先攒在 draft 里，点确定才交出去）。**别统一。**
- 表盘直径走 `face` 参数（`R = face/2 - 29`，246 → 94 正好是原来写死的值）。面板里给 198，
  **抽屉里仍是 246** —— `.clock-pop` 的 278px 宽度是按 246 配出来的（见「浮层的宽度要按
  内容盒算」），给它套小字会顶到边。
- **表盘上面那个大号的时间显示没有了**（`.cp-display` / `.cp-cell` / `.cp-colon` 三块整组
  删掉）。生效时间早就写在横条那个按钮上（`.fast-clock .fc-t`），面板里再重复一遍纯属占
  地方 —— 这个面板只有 234px 宽，表盘已经占掉 198。
- **时 / 分圈的切换改由表盘正中心那个点承担**（`.cp-dot`，点一下切圈，上面写「时」/
  「分」）。那是**状态**不是提示：不写的话，同一个位置上那 12 个数是 12 点还是 12 分，
  只能靠数数猜。
- **「现在」在上午 / 下午那一组的右侧，但那一组仍然居中** —— 所以「现在」是**绝对定位**，
  不是当第三个 flex 子元素（那样 `justify-content: center` 会把三个一起居中，上午 / 下午
  整组左偏，而这两个键的居中是面板的视觉基准线）。
- **下午那圈写 12–23，不是 13–24**：24 点在钟面顶端对应的是 12 点（正午），标 24 会点出
  12:xx，标签和结果对不上。13 落在 1 点钟位置，手感不用重学。**分钟那圈写 60,5,…,55**，
  跟真钟表的分钟圈一样，顶端那个 60 就是 0 分。
- **`ClockBody` 里没有 24 小时制的数字显示**，所以「上午 12 点 = 00:xx」这件事只在**横条
  按钮**和抽屉的时间框上看得到。别去面板里找那两个数。
- 「现在」跟着表盘走（它拨的是针），所以它在 `ClockBody` 里；「清除 / 取消 / 确定」是出口，
  留在 `ClockPop` 里。

### 时钟按钮点下去先出日期面板、选完再出时间转盘（需求 3）

顺序是「日期 → 时间」：日期决定这条任务落在哪一天，时间只在有日期时才有意义。

- 日期面板是 `ui/DatePop.tsx` 的 `DatePop`，里面的月历 `MiniCalendar` **与顶栏「找日期」
  的 `JumpPop` 共用同一份**（`data-jump` / `.jp-*` 那套原样复用，连密度短横的 `loadOf`
  都是同一个 `jumpLoad(state, iso)`）。**别再写第二份月历。**
- 时间那一层就是原来的 `ClockPop`，一行没改。
- **默认值由 `domain/model.ts` 的 `quickDefaults(ui, todayIso)` 给**，单测锁着：待办箱 =
  无日期无时间；日程页 = 当前 `cursor` 那天（cursor 空就是今天）；其余（今天 / 逾期 /
  打卡 / 已完成 / 项目）= 今天。放在领域层而不是 `Shell.tsx`，就是为了能被单测钉住 ——
  它只读 `nav` 与 `cursor`，所以收 `Partial<UiPrefs>`。
- **生效值的优先级是 面板选的 > 文本解析的 > tab 默认的。** 注意时间那一档与旧版**相反**
  （旧版是「文本解析的 > 面板选的」）—— 用户刚在转盘上点的那一下必须赢过他打的字，否则
  就是「点了没反应」。
- 待办箱的默认是**无日期**，所以日期面板必须有「不选日期」这条出口（`.dp-foot` 里，另有
  「取消」只关面板、保留已选）。否则点开就只能选一个、回不去。
- 占位符**不随 tab 变**（`QUICK_PLACEHOLDER` 一个常量）。按 tab 换文案会让用户以为「切个
  tab 我刚打的话被吃了」；已经打进去的字本来就是 React 状态，切 tab 不卸载 `QuickAdd`，
  所以不会丢。

## 移动端软键盘避让：`--kb`（2026-10-06）

`dvh` 跟的是**布局视口**，而软键盘只压小**可视视口** —— 所以 `100dvh` /
`88dvh` 一个像素都不会躲。**固定定位的那几个面**（详情抽屉、`Sheet`、登录页）
浏览器也不会替我们滚上来的。所以：

- `ui/hooks.ts` 的 `useKeyboardInset()` 用 `window.visualViewport` 量出
  被遮的高度，写进 `document.documentElement` 的 **`--kb`**；
- 消费点三处：`kit.tsx` 的 `Sheet`（`pb-[var(--kb,0px)]`，无条件）、
  `styles/overlays.css` 里 ≤900px 的 `.drawer`（`padding-bottom`，宽屏是侧栏面板、
  键盘盖不到）、`ui/Auth.tsx` 的登录卡（`pb-[calc(1.5rem+var(--kb,0px))]`）。
- 登录卡还额外改成 **可滚 + `my-auto` 居中**，不用 `items-center`：
  内容比容器高时居中会把顶裁掉且滚不上去。

> **页内正常滚动的输入框不用管** —— 那些浏览器自己会滚。
> 改了需要避让的固定面板，记得接上 `--kb`，别写死一个 padding。

**锁在哪**：`browser-smoke.mjs` **第十五节**。它只验**管道**（有人写 `--kb`、
有人读 `--kb`），**验不了**「visualViewport 变化 → 算出多少像素」那一步 ——
无头里造不出真软键盘（和触屏那条同理，真机手感只能人看）。
验过它有牙：把 Sheet 那句 `pb-[var(--kb,0px)]` 摘掉重跑，
「容器读到了 --kb」当场变成 `0px`。
