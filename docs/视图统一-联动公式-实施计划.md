胶囊才不会因为「卡自己也留 2px」而少掉文字宽度（格子 48.8 − 0 − 卡 4 − 框 2 = 42.8）。

日期字号 16 → **13**、圆圈 26 → **22**（窄屏 15 → **12**、24 → **20**）；
`.week-head-cell` padding `8px 0 6px` → **`5px 0 4px`**（窄屏 `7px 2px 5px` → **`4px 1px 3px`**）。

**③ 拖卡时区域跟着滑**：触摸 `delay: 480` → **300**（鼠标 `distance: 8` 不动）；
`provider.tsx` / `sortable.tsx` 两处 `autoScroll={false}`；卡片表面 `user-select: none`
（**列表行 `.task-row` 特意不收** —— 那儿的文字本来就要复制）。根因与证据分级见
[踩坑 51](踩坑-前端.md)：**300ms 那半边是测出来的**（380ms 起拖 / 200ms 不起拖、
开拖后 3 个 touchmove 全拦下、不长按时 3 个全放行），**AutoScroll 那半边只有库源码证据**
（无头合成触摸不驱动原生滚动，A/B 两版探针读数一样）—— 真机要手工走一遍。

**仍然故意不一样的两处**（第二轮确认不变）：桌面日视图未定时卡仍是三列网格；
窄屏月 pill（52.86px 宽、标题可用 46.86px）仍不显示勾选圈与时间 —— 24×24 命中区塞进去
就没地方写字了。**2026-10-24 用户确认：不要加**（要勾完成走抽屉）。

## 第四轮（同日，用户三项反馈：时间行与标题文字左对齐 · 打勾太大且位置不对 · 时间行该不该显示）

三项的判据、实测数字、以及**与用户字面要求不同的那一处**，都在这一节。

**① 时间行左端 = 标题文字左端**（不是卡片左边缘、不是勾选圈）。
原先 `.ev-time` / `.ev-note` 各写死 `padding-left: 21px`，那个数是照「圈 14 + gap 2 + 边框」
**估**出来的 —— 圈一改就漂，实测偏 5px。现在卡片内容层是「圈 + 文字块」两件：
`.ev-body` 单行 flex，标题 / 时间 / 详细内容全在 `.ev-text`（单列网格）里，
**左端只有这一处定义**。实测六屏 `时间行左端 − 标题左端 = 0.00`（容差 0.5px）。

**② 圈直径跟字号走**：`--check-size = min(16, max(9, 字号 × 0.85))`。
以前是三档写死（本体 18 / `.sm` 14 / 窄屏又 22），12.5px 的字旁边挂 18px 的圈，圈比字大；
`.sm` 这一档取消，`<CheckBtn>` 没有 size 参数了，勾的笔画按 `--check-size` 比例缩放，
命中区仍靠 `::before` 撑到 24×24（视觉尺寸不变）。实测：桌面卡 **10.63**（字号 12.5）、
窄屏卡 **9.34**（11）、列表行 **11.47**（13.5，`::before` 24×24）。
圈的中心由 `align-items: center` 落在**整块文字**的中线上（实测差 ≤ 0.02px）——
原先用 `grid-row: 1 / -1` 跨行居中，**只跨显式行**，隐式行不算数，圈只盖住标题那一行、
中心偏上 6px（最小复现 −6.03，探针里 −6.04）。见[踩坑 52](踩坑-前端.md)。

**③ 时间行只由时长决定**：`> 60` 分钟一定有，`≤ 60`（含整 1h、含没设过时长的）没有，
**月视图永远没有**（时间挂 `title` 气泡）。原先同一件事在三个地方各决定一遍：
`TaskCard` 判一次、窄屏周视图 `.ev-time { display: none }` 再藏一次、月胶囊画不画第三种画法。
现在判据只在 `TaskCard` 一处，`display: none` 那条已删。

装不下的两级修法：**先压行距**（`--ev-title-lh` ≈ 字号 × 1.1、`--ev-time-lh` ≈ × 1.0），
**再不够给这张卡加长** `min-height`。61 分钟那条卡是触发门槛，实测（探针第三节逐张量）：

| 屏 | 61 分钟卡实测高 | 加长 | 对照：60 分钟卡（无时间行） |
|---|---|---|---|
| 日 1400 | **28.25** | ✅ 顶到 28.25 | 25.80 |
| 周 1400 | **28.25** | ✅ 顶到 28.25 | 23.95 |
| 日 390 | **25.59** | ✅ 顶到 25.6 | 22.02 |
| 周 390 | **25.59** | ✅ 顶到 25.6 | 20.45 |

（「顶到」= 写进 `min-height` 的 `lineBudget().tightPx`：桌面 `12.5×1.1 + 10.5×1.0 + 2 + 4 = 28.25`、
窄屏 `11×1.1 + 9.5×1.0 + 2 + 4 = 25.6`。探针只量**最终**高，自然高不单独量 ——
所以这一列是「加长之后」的实测，不是差值。）
75 分钟那条在窄屏周视图自然够（25.94，没顶）；120 / 90 都不加长。

⚠️ **这一处与用户的字面要求不同**：用户说的是「不够就**压缩字体**」，
落地的第三级是**给卡加长**、字号一个字不动。理由是同一屏上两张卡字号不一样会像两版皮肤
（`calendar.css` 里本来就有这条规矩）。**要真按字面做，改 `lineBudget()` 里那两行 `tight*` 即可**
—— 现在留在这儿没做，等你定。

**探针**：`card-geometry.mjs` 第三节（六屏 × 逐张卡，种子 120 / 90 / 75 / 61 / 60 / 45 分钟各一条 ——
61 与 60 挨着放，就是为了让「一小时」这个边界被跨过而不是被绕过）。
月视图那条断的是**元素数量**（`.pill-time` 现在根本不渲染，数出来必须是 0），不是「看不见」。
