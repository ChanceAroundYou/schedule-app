# 视图统一 + 高度联动 —— 文件级实施清单

> 状态：**待开工**（需求已收敛，实现未开始）
> 与 `docs/重构-组件合并-实施spec.md` 不重叠：那份做浮层 / 图标 / 大文件拆分，这份只做三视图任务卡与时刻线。
> 公式回顾：日 `C = (H − 4×gap − peek) / (N＋3)`；周 `C = (H − 周表头高 − 4×gap − peek) / (N＋3)`；
> `gap = 2px`，`peek = 3px`，顶部留白 = 一条 gap，无 `padding-bottom`；C 不设下限。
> 不变量：`domain/` 零 React / DOM / 网络；外部 import 路径尽量不变。

## 追加 · 2026-10-24：「一小时卡」与「无时间卡」处处一样 ✅

用户三轮反馈（第 1 轮：1 小时卡与无时间卡高度明显不同 / 圆角固定值在不同高宽的长方形上
圆润程度不同 / 打勾按钮统一加回来、与文字间距 2px；第 2、3 轮：高度 宽度 圆角 左右 margin 仍不一致）。
根因三条见 [踩坑 50](踩坑-前端.md)。**改完用临时量尺在 dev 服务上实测**（1400×900 与 390×844）：

| 视图 / 视口 | 定时卡 高 × 宽 | 未定时卡 高 × 宽 | 圆角 | 左 x | padding |
|---|---|---|---|---|---|
| 日 1400 | 25.80 × 1042 | 25.78 × 346.66（三列网格，宽是设计） | 7.74 / 7.74 | 323 / 323 | 7 / 7 |
| 周 1400 | 23.59 × 151.58 | 23.63 × 151.58 | 7.09 / 7.09 | 1071.84 / 1071.84 | 7 / 7 |
| 日 390 | 22.02 × 151.5 | 22.00 × 306（单列，宽是设计） | 6.60 / 6.60 | 62 / 62 | 6 / 6 |
| 周 390 | 20.08 × 34 | 20.13 × 71 | 6.04 / 6.04 | 232 / 232 | 0 / 0 |

残差 ≤ 0.05px，来自「百分比高 × 含 1px 边框的容器高」的取整。**判据**：圆角断言写
`radius / 卡自身高 ≈ 0.3`，不写死像素档。

**仍然故意不一样的两处**（不是没收敛）：

- 桌面日视图未定时卡是**三列网格**（1/3 宽），定时卡占满一整列 —— 布局不同，高 / 圆角 / 留白相同。
- 窄屏月视图 pill（45px 宽）**不显示勾选圈与时间**：`24×24` 命中区 + 标题在 45px 里放不下
  （要勾完成走抽屉）。桌面月 pill 的勾选圈在。
