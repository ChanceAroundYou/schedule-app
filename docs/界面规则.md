# 界面硬规则

> **改任何 UI 之前先读这一份。** 这里只写「不许破」，每条都对应一处会被静默破坏的地方。
> 像素怎么算、为什么是这个值 → [界面约定.md](界面约定.md) 及 `-布局` / `-无障碍` / `-快速添加` 三册。
> 组件 API → [组件库.md](组件库.md)。踩坑编号 → [踩坑.md](踩坑.md)。

---

## 一、交互语言

**统一「列表 → 详情 → 编辑」三段式**；删除走应用内确认弹层（`useConfirm`）。

- 界面不出现「备忘录 / 笔记本 / 清单」；文案统一「打卡」不是「习惯」（`habits` 名保留）。
- **任务是「标题 + 详细内容」**：界面叫「详细内容」，字段名仍是 `note`（改名等于数据迁移）。
- **点日历空格子 = 就地新建**，落点由**按下位置**决定（`app/tapSnap.ts` 的 `pointerdown` 快照），
  回车落成、Esc 取消。**抽屉是「补细节」，不是新建入口。**
  > 键盘弹起时界面压矮：`e.clientY` 是按下坐标、`getBoundingClientRect()` 是 click 时布局，
  > 混用会把 21:00 算成 7:00。**不要改回「click 时读 rect」。**
- 深浅色两档（`ui.theme`）、风格三档（`ui.style` → `data-style`）。**色板没有。**
- **图标一律 lucide，零 emoji；弹层一律应用内，零原生 `confirm` / `alert`。**

## 二、令牌五条

1. **`.tsx` 引用 CSS 变量一律不给兜底值** —— 有兜底值时两套主题都在用写死的浅色，
   静默降级比坏掉难查得多。
2. **`--border`（装饰线）与 `--input`（交互描边 ≥3:1，WCAG 1.4.11）按「能不能操作」分档**；
   焦点环在 `styles/responsive.css` 最末 `:focus-visible`，**必须和 `--input` 一起改**。
3. **风格轴两半**：线宽 `--border-w`，圆角 `--r-xs/sm/md/lg/xl/pill`；
   **`.tsx` 不许出现 Tailwind 自带 `rounded` / `rounded-lg` / `rounded-2xl`**（写死像素，切档原地不动）。
4. **卡片圆角跟卡自己的短边走，全项目只此一条算式**：
   `min(var(--r-xl), max(2px, calc(var(--card-h) * var(--card-r-k))))`；
   每种卡把高度报进 `--card-h`（定时 `--card-px`、未定时 `--row`、月胶囊 `--pill-h`）。
   **同一属性只声明一处**（后写的同特异度老皮肤会静默吃掉，[踩坑 50](踩坑-前端-组件.md)）。
   **用 `min()` / `max()` 不用 `clamp()`**（flat 档 `--r-*` 全 0，`clamp(2px,x,0)` 返回下限）。
   横向留白只有 `--card-pad-x`，**容器横向 padding 一律 0**。
5. **勾选圈视觉直径 = 所在行字号 × `--check-k`，夹 `--check-min`~`--check-max`**
   （现 k=1、夹 9~18px；列表行报 `--check-fs: var(--fs-row)`）。
   **别在 `.tsx` 或响应式里再写一档尺寸**（[踩坑 52](踩坑-前端-组件.md)）。
   勾选圈一律走 `views/parts.tsx` 的 `<CheckBtn>`，**别再手写 `span.check-btn`**。

> 1–3 由 `contrast.mjs` / `color-scan.mjs` 锁，4–5 由 `card-geometry.mjs` / `browser-smoke.mjs` 锁。

## 三、时间与卡片

- **时间行只由时长决定**：`> 60 分钟` 一定有，`≤ 60`（含整 1 小时、含没设时长）没有；
  **月视图永远没有**（时间挂 `title` 气泡）。判据只在 `TaskCard` 一处，别处不许再写 `display: none`。
- **上下把手也按时长走**：`≥ 60 分钟` 一定有两个；`< 60 分钟` 的才受 26px 像素门槛管。
  别改回纯像素判据（同一张 60 分钟卡桌面 27px、窄屏 20px）。
- **卡缝四边都是 1px**（`CARD_SEAM`）：上 / 下 / 右由 `TaskCard.tsx` 内联扣，
  未定时卡右边在 `calendar.css` 的 `.task-el--untimed` 扣（**两处必须同值**），
  间距是容器的 `--un-gap: 1px`。**单列也要扣。**
- **装不下只许压，不许加长**。`useCardFit` 按两个轴分别压：

| 轴 | 判据（量出来） | 阶梯 |
|---|---|---|
| 纵向 | `.ev-text` 的 scrollHeight > `.ev-body` 的 clientHeight | 行距 → 卡内留白归零 → 标题字号（下限 9px） |
| 横向 | `.ev-time` 的 scrollWidth > clientWidth | 紧凑写法先省 → 字距收紧 → **时间行自己的**字号（下限 7.5px） |

  **横向那一轴不许动标题字号**。两轴档位写在卡上 `data-fit`（形如 `v1h2`），探针按它读数。
  卡片文案走紧凑写法（`timeRangeCompact` → `09:30–10:30`），抽屉 / 列表 / `title` 仍是完整写法。

## 四、跨集口径

- **今天 / 逾期 / 待办箱 / 垃圾箱 / AI 看全部；日程 / 打卡 / 已完成 / 项目只看顶栏勾选的集**（`ui.cals`）。
  表达方式是 `Workbench.tsx` 给视图传哪份 state（`state` 全量 / `scoped`），
  **不要**给 `views/` 选择器加 `calId` 参数。**侧栏徽标与顶栏一律全量口径。**
- **勾选（`ui.cals`）和归属（`ui.cal`）是两件事**：前者「同时看哪几个」，后者「新建落哪儿」。
  `store.toggleCal()` 保证归属的集一定勾着，**至少永远有一个集勾着**。

## 五、只读 / 状态

- **只读成员不是「藏起来」，是「点了会告诉你为什么」**（`commitMany()` 挡下时 `denied` +1，
  弹一次提示，**别让写操作静默失败**）。记录只有 `store.ts` 的 `deny()` 一个入口，
  **提示要点名是哪个集**（`deniedCals`）。
- **断网时界面必须说话**：顶栏 `.sync-dot` 显示 ☁︎ 划掉（`CloudOff`）配 title
  「离线，改动先存在本机，联网后自动同步」，**不是**一直转的加载圈。
  来源是 `ui/hooks.ts` 的 `useOnline()`，**不是**「上一次请求成不成功」。
- 有登录，但**没有密码找回、邮箱、第三方登录，也没有管理员**。别在界面上提「管理员」。

## 六、无障碍

1. **每个控件都要有可访问名字**：有可见标签 → `useId()` + `<label htmlFor>`；无标签按钮组
   → `aria-label`；纯图标按钮 → `<IconBtn label="…">`；**有文字的按钮什么都不用加**。
   > **`placeholder` 不算名字**（输入后就没了）。探针取可访问名字的函数也**不许接受 placeholder**。
2. **命中区 ≥ 24×24（WCAG 2.5.8），视觉直径跟字号走**，靠 `::before` 撑命中区 ——
   **不是把圆点画大**（探针在边界读到 23 是取整，别为一格改 CSS）。
   圈必须是**所在文字的竖直中心**：`.ev-body` 的 `align-items: center` 保证。
3. **盖住整页的浮层四件事**：`role="dialog"` + `aria-modal` + 名字 · `useFocusTrap(panel, open)` ·
   开时焦点送进**面板本身**（送进输入框会当场弹软键盘）· 关时 `prevFocus.focus()` 还回。
   > 记「原来那个元素」前先看焦点在不在浮层里；遮罩加 `aria-hidden="true"`。
   > 浮层焦点环关在 `responsive.css` 末尾 —— 必须写那儿：Tailwind 的 `outline-none` 在 `@layer` 里压不过
   > （[踩坑 17](踩坑-前端-交互.md)）。
4. **状态语义别混**：`aria-current="page"` = 现在在哪页；`aria-expanded` = 真的是折叠开关；
   `aria-haspopup="dialog"` = 按下弹浮层，开没开在 App 那层。
5. **键盘只做一档微调**：两个时间把手给 `tabIndex={0}` + `aria-label`，方向键走 `nudgeEdge()`
   （和鼠标共用算式），↑/↓ 一次一档 15 分钟。**别再加别的键位。**
6. **`prefers-reduced-motion` 全站关**（`responsive.css` 最末，通配 `*` + `!important`），
   **无例外**（同步圈也停）。会动的地方十几处，挑漏一处等于没关。

## 七、文案

**默认不写，写就一句，不把人当傻子。**

| 该写 | 不该写 |
|---|---|
| 危险操作的后果（「删了找不回来」） | 「请记得」「别忘了」「千万」 |
| 反直觉的行为（「导入是合并，不覆盖」） | 用户看得见的东西 |
| 不可逆的事 | 枚举不存在的功能 |
